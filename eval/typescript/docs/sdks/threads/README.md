## Overview

* [threadsList](#threadslist) - List Threads
* [threadsGet](#threadsget) - Get Thread
* [threadsUpdate](#threadsupdate) - Update Thread

## threadsList

**CLI:**
```bash

```

## threadsDelete

Moves the thread to trash by adding a trash label to all messages. If the thread is already in trash, it will be permanently deleted. Use `permanent=true` to force permanent deletion.

**CLI:**
```bash
agentmail threads delete --thread-id <thread_id>
```

### Example Usage

<!-- UsageSnippet language="typescript" operationID="threads_delete" method="delete" path="/v0/threads/{thread_id}" -->
