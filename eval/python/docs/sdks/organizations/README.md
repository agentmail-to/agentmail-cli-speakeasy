# Organizations

## Overview

### Available Operations

* [organizations_get](#organizations_get) - Get Organization

## organizations_get

Returns the organization for the authenticated API key (usage limits, counts, and billing metadata).

**CLI:**
```bash
agentmail organizations get
```

### Example Usage

<!-- UsageSnippet language="python" operationID="organizations_get" method="get" path="/v0/organizations" -->
```python
from agentmail import AgentmailCli


with AgentmailCli(
    bearer_auth="<YOUR_BEARER_TOKEN_HERE>",
) as agentmail_cli:

    res = agentmail_cli.organizations.organizations_get()

    # Handle response
    print(res)

```
